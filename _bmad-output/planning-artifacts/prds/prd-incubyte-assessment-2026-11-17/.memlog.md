- (decision) User wants a single PRD document only (no addendum or extra files); source is assessment brief
- (decision) Working mode: Coaching path (user chose)
- (decision) Entry point: Vision + Features (capability-first); single operator persona HR Manager
- (decision) Priorities: analytics > currency/data consistency > anomaly detection > record management
- (decision) Demo questions: pay per country; avg Software Engineer salary by country; fairness within role+location; top/bottom paid per department; payroll impact of 10% raise
- (decision) Needs: salary change history (what/when/who); currency normalization for cross-country comparison
- (decision) Auth: email/password, multiple HR accounts, no public signup, no RBAC; audit = user id, timestamp, prev and new value
- (decision) Currency: USD reporting, local storage, seeded admin-editable rates, no live API; 8 countries totalling 10,000
- (decision) Anomaly: >20% from peer-group median (country+dept+title), min 5, flagged as potential only
- (decision) Simulator read-only, scope org/country/department, shows current/additional/projected
- (decision) Model: Employee separate from Compensation Record with effective dates; revisions not overwrites
- (assumption) Active-only analytics; single rate per currency; ~8 depts/25 titles; currency matches country; rate edits audited
